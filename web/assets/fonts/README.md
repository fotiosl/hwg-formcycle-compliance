# Schriften

`lexend-latin-wght-normal.woff2` ist die Schrift Lexend (variable Strichstärke, Latin-Teilmenge) aus dem npm-Paket
`@fontsource-variable/lexend@5.2.8`. Copyright 2018 The Lexend Project Authors (https://github.com/googlefonts/lexend),
lizenziert unter der SIL Open Font License 1.1 (https://openfontlicense.org).

`scripts/generate_web_dashboard.py` bettet die Datei in `web/compliance_dashboard.html` ein, damit das Dashboard keine
externen Server (z. B. Google Fonts) kontaktiert.
